# Velora

Velora 是一款基于 Electron + Vue 3 + TypeScript 构建的桌面端多媒体资源聚合、下载与处理工具。

## 基本功能

- **多源资源管理**：支持挂载本地媒体文件夹、收藏网络资源站点（内置独立会话浏览器、广告拦截、自定义脚本/样式与站点缓存清理）、接入 CMS 影视资源站，以及多网盘资源解析与访问。
- **媒体嗅探与下载**：支持网页视频快捷嗅探、自定义解析规则、HTTP 多线程下载与 M3U8 分片下载合并，支持按媒体类型与规则自动匹配保存目录。
- **视频剪辑与压缩**：内置基于 FFmpeg 的视频片段剪辑、多视频合并、下载后自动压缩与手动压缩，支持硬件加速编码与自定义限速倍速。
- **局域网共享**：可一键开启局域网共享服务，通过链接或扫码在手机及同网段设备中浏览和管理本地媒体资源，支持自定义端口与访问密码。
- **偏好与备份**：支持深浅色主题切换、系统托盘常驻，以及按模块导出/导入配置备份。

## 环境要求

- **Node.js**（建议 v18 及以上）与 **npm**
- **FFmpeg / FFprobe**（需已添加到系统 `PATH`，用于视频压缩、剪辑、合并与 M3U8 转封装）

## 运行与打包

### 1. 安装依赖

```bash
npm install
```

### 2. 开发模式运行

```bash
npm run dev
```

### 3. 构建打包

- 生成免安装目录版：

```bash
npm run build
```

- 构建 Windows 安装包（NSIS）：

```bash
npm run build:win
```

构建产物默认输出在项目根目录的 `release/` 文件夹中。

## 快速使用

1. 启动应用后，打开右上角 **设置**，配置图片、音频、视频与文件的默认下载目录。
2. 在 **设置** 中按需添加 **本地资源目录**、**网络资源站点**、**CMS 资源站** 或登录 **网盘账号**。
3. 返回主页点击对应卡片，即可浏览媒体、嗅探并下载音视频，或在本地资源中对视频进行播放、剪辑、合并与压缩。
4. 如需在手机或其他设备访问本地资源，可在 **设置 → 本地资源** 中开启 **局域网共享服务** 并扫码打开。
